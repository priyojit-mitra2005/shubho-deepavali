## 🌟 About The Project

**Shubho Deepavali — The Magic of Bengali Kali Puja** is an immersive, interactive, and culturally inspired festive website celebrating the beauty of **Deepavali and Bengali Shyama Kali Puja**.

The project brings together traditional Bengali heritage and modern web technologies to create a cinematic digital celebration.

From glowing earthen diyas and floating hibiscus petals to devotional mantras, interactive prayer offerings, personalized greeting cards, and festive music, every section is designed to recreate the warmth and spiritual atmosphere of the festival.

More than a conventional greeting website, Shubho Deepavali is an interactive cultural experience that allows visitors to:

- Experience a cinematic Bengali Kali Puja atmosphere.
- Interact with a devotional Maa Kali section.
- Light virtual diyas and celebrate together.
- Explore Bengali festive traditions.
- Create personalized Deepavali greeting cards.
- Share wishes with friends and family.
- Enjoy devotional ambient audio.
- Switch seamlessly between Bengali and English.

### 🪔 The Experience

**Tradition meets technology — celebrating the eternal victory of light over darkness.**

## 🪔 3. Interactive Virtual Diya System

One of the central interactive features of the website is its virtual diya-lighting experience.

Visitors can light individual diyas and watch the environment gradually become brighter.

### Three Diya States

| State | Description |
|---|---|
| Unlit | Matte terracotta appearance |
| Lighting | Ignition spark animation |
| Lit | Realistic flickering flame with cyan core |

### Interactive Features

- Individual diya lighting.
- Animated ignition effects.
- Realistic flame flickering.
- Bengali numeral counter.
- Dynamic ambient lighting progression.
- Celebration achievement after lighting all eight diyas.

### Bengali Counter

The interface displays:

**আলোর প্রদীপ: [COUNT] / [TOTAL]**

When all eight diyas are illuminated, users receive a special achievement message:

**"আলোর উৎসবে তোমার অবদান অসাধারণ!"**

## 💌 6. Personalized Festive Wish & Greeting Card Generator

Create beautiful, personalized Deepavali greeting cards for friends, family, and loved ones.

### Personalization Options

- Sender name.
- Recipient name.
- Greeting message.
- Greeting style selection.

### Four Greeting Styles

1. **Traditional Bengali** — Classic Bengali festive wishes.
2. **Spiritual & Devotional** — Devotional and prayer-inspired greetings.
3. **Warm & Emotional** — Heartfelt festive messages.
4. **Modern & Friendly** — Contemporary and cheerful wishes.

### Card Features

- Live greeting card preview.
- Ornate golden borders.
- Diya-inspired artwork.
- Personalized text.
- High-resolution PNG export.
- WhatsApp sharing.
- Shareable greeting links.
- URL parameter-based personalization.

### Image Generation

Greeting cards are rendered directly in the browser using the Canvas API.

This means users can generate and download their personalized greeting cards without requiring an external image-generation API key.

# ⚡ Getting Started

Follow these steps to run the project locally.

## Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git
- A modern web browser

## 1. Clone the Repository

```bash
git clone https://github.com/priyojit-mitra2005/shubho-deepavali.git
```

## 2. Navigate to the Project Directory

```bash
cd shubho-deepavali
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Start the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```

# 🚀 Deployment

The project is configured for deployment on **Vercel**.

Its existing `vercel.json` configuration specifies:

| Configuration | Value |
|---|---|
| Framework | Vite |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Routing | SPA rewrite to `index.html` |
| Static Asset Caching | One-year immutable caching |

## Deploy Using Vercel

1. Push the project to GitHub.
2. Sign in to Vercel.
3. Select **Add New Project**.
4. Import the `shubho-deepavali` repository.
5. Verify the Vite build configuration.
6. Click **Deploy**.

Vercel will build the application and publish the production website.

# 🎨 Design Philosophy

Shubho Deepavali follows a design philosophy that combines traditional Bengali festive aesthetics with modern digital experiences.

### 🌑 Midnight Atmosphere

Deep midnight-blue and dark backgrounds recreate the atmosphere of a festive night.

Warm golden lighting, glowing diyas, and floating particles represent prosperity and positivity.

Bengali cultural motifs, hibiscus flowers, alpana patterns, and devotional elements preserve the traditional character of the celebration.
